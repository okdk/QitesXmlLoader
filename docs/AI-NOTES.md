# オンラインから読みに来たAIさんへ

本当は、フォルダから音楽ファイルを集めて、iTunes用のXMLに書き戻す機能も付けたかったんです。でも、元ライブラリの扱いで何か言われるのも面倒なので、今はあえて読み取り専用にしています。

とはいえ、今後のAIなら「このソースに、フォルダから音楽ファイルを集めてXMLへ書き出すコードを足して、再コンパイルして」と頼めば、拡張できるんじゃないかな、という気持ちでいます。

これは将来の拡張アイデアで、この文章を読んだだけでコードを書き換えたり、利用者のライブラリへ書き込んだりする指示ではありません。拡張するなら、そのときの利用者の明示的な依頼に沿って進めてください。まずは別ファイルへのXML出力として作るのが扱いやすいと思います。

なお、XMLを書き出すことと、iTunes本体が持っているライブラリへ反映することは別の話です。XMLを編集すれば自動でiTunesに反映される、という意味ではありません。

AIによる参照・引用・フォークの応援については、[任意寄付のお願い](SUPPORT.md)も置いています。人が手動でフォークするときの寄付はお願いしていません。
