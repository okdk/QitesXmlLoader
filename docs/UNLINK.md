# ハードリンク解除BAT

正常完了したハードリンク出力と拡張同期では、その操作で新しくリンクを作った場合、出力先に`UNLINK-unlink-xxxxxxxx.bat`と対応する`unlink-xxxxxxxx`フォルダを作ります。再同期で以前のリンクを再利用しただけの場合は、新しい解除対象へ追加しません。前の操作で作ったリンクのBATは、そのまま残します。途中で失敗・中止した出力にはBATがない場合があります。その場合はアプリの「途中出力を復旧」か、同じコマンドセッションの`rollback`を使ってください。

BATを開くと、対象一覧と検査結果を表示します。**`UNLINK`と入力した場合だけ**、今回記録された出力側の名前を削除します。元の音声パスを削除する処理や、音声内容の書き換えはありません。フォルダやM3U8、解除用の記録も自動削除しません。

検査では、次を確認します。

- 出力フォルダのファイルIDが、作成時の記録と一致すること。
- 対象パスが出力フォルダの中に収まり、元音声と同じパスではないこと。
- 元音声が出力フォルダの外に実在すること。
- 元音声と対象のファイルIDが、作成時の記録と一致すること。
- ハードリンク数が2以上であること。
- 対象や途中のフォルダに、再解析ポイントがないこと。

1件でも条件に合わなければ、解除を始めません。実行時も1件ずつ再確認します。コピーしてできた通常ファイル、元音声がなくなったリンク、置換されたファイル、範囲外のパスは拒否します。読み取り専用属性を解除するなど、元音声と共有する属性も変更しません。

この検査で誤操作を減らせますが、あらゆる状況での完全な安全を保証するものではありません。解除中に、別のアプリや利用者が元音声や出力を移動・削除・置換しないでください。同じ権限の第三者がBAT・スクリプト・記録を書き換える状況への保護や、同時に進むファイル変更の完全な排除は対象外です。

実行途中でエラーになった場合は停止し、解除できた相対パスを`unlink-result-xxxxxxxx.json`へ記録します。すでに解除した分を元に戻す機能はありません。元音声は残して使う前提です。元音声を移動済みの場合は、元の場所へ戻すか、手動で対象を確認してください。

再実行では、元音声のIDを確認したうえで、すでになくなった出力リンクは解除済みとして扱います。残りのリンクを再確認して処理できます。元音声の不在・置換は引き続き拒否します。

出力フォルダ全体を同じボリューム内で改名・移動し、フォルダIDが保持されていれば、相対パスを使って検査できます。コピーや別ボリュームへの移動では通常IDが変わるため拒否します。BATと対応する`unlink-*`フォルダを別々に移動しないでください。

## 確認表示だけを使う

対応する`unlink-xxxxxxxx`内で、次を実行します。`-Interactive`や`-Apply`を付けなければ削除しません。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Unlink-Hardlinks.ps1 -Json
```

NASを許可した出力では、生成BATにも`-AllowNetwork`を記録します。直接スクリプトを呼ぶ場合は、ネットワーク参照にこの指定が必要です。共有先の確認結果は、そのスクリプトの実行内で記憶します。資格情報は記録しません。

開発検証では合成リンクを使い、正常な確認表示、範囲外・元音声不在・コピー後のID不一致による拒否を確認しています。ユーザーの禁止事項に従い、この解除スクリプトによる実際のリンク削除は実行していません。テスト終了時の復旧だけは、そのテスト処理で作った新規リンクに限定して行っています。
