# 再生欄とほかのアプリ向けの書き出し

再生欄では「再生対象」「再生順」「再生デバイス」を選びます。出力テスト音ボタンの右に、曲のシークバー、経過時間、全体時間、表示中のプレイリストでの位置と総時間を表示します。幅が狭いときはシークバーと経過時間を残します。

シークバーはクリック、ドラッグ、矢印キーで操作できます。一時停止中に位置を変えても、一時停止を保ちます。プレイリスト内の時間は、画面に表示しているリストのXML上の曲順を基準にします。ランダム再生ではその曲の元の位置を示し、ループを何周したかは加算しません。別のリストに切り替え、その中に再生中の行がないときは、位置を「—」と表示します。プレイリストの総時間にはXMLに保存された曲の長さを使います。

## 選択した曲を書き出す

1. 曲一覧で曲を選びます。Ctrl・Shift・ドラッグで複数曲を選べます。
2. 出力方法と出力先を選び、「読み込み先」で対象アプリを選びます。
3. 「選択中の曲を書き出す…」を押し、確認画面で内容を確認します。

このボタンは、チェックしたプレイリストではなく、曲一覧から選択に追加した曲を出力します。複数のプレイリストをまたいだ選択も含みます。選択した順番を保ち、同じ曲でも異なるプレイリストの行は別の項目として扱います。

出力先の中に、新しい`QitesXmlLoader-xxxxxxxx`フォルダを作ります。完了時のステータス欄に、そのフォルダの場所を表示します。

MusicBee・foobar2000・AIMP向けは共通の形式です。音声フォルダと、UTF-8の`selection.m3u8`、UTF-8 BOM付きの`selection.m3u`、各フォルダのリストを作ります。まず`selection.m3u8`を対象アプリで開いてください。アプリ固有のデータベースは作成せず、相手先アプリの起動や設定変更もしません。

相対パスなので、フォルダとリストをまとめて別の場所へ移せます。音声だけを別の場所へ移すとリストから参照できなくなります。元ファイルをコピーするモードとハードリンクモードではFFmpegは不要です。ハードリンクを作る場所は元ファイルと同じボリュームにしてください。Androidへ移すときはフォルダの中身を通常のファイルとしてコピーします。

## reTONE向け

`Music`フォルダに連番付きの音声ファイルとリストを作ります。`Music`の中身を端末の`Music`フォルダへコピーしてください。ファイル名は`0001-正規化した曲名.拡張子`です。日本語を残し、全角英数・半角カナなどをNFKCでそろえ、空白や記号をアンダースコアにまとめます。元の曲名はリストの曲情報に残します。1万曲以上では連番の桁数を増やし、文字列順でも順序を保ちます。

reTONEの公開仕様では、外部プレイリストの読み込みに対応していません。そのためM3U8は曲順の控えであり、reTONE内にプレイリストを自動作成するものではありません。ファイル名順を選べる場合に、連番を使って曲順を再現できます。タグ順など別の並べ方では、連番だけで曲順を強制できません。

通常は、ほかの相手先にも日本語を残します。ファイル名を扱えない古いソフト向けに限り、「互換性のためファイル名を英数字にする」を選べます。日本語の文字は`u`と16進数の識別表記にし、リスト内の元の曲名は変えません。拡張ハードリンク同期も連番付きになりますが、過去に作ったリンクは削除しません。並び替えで不要になったリンクは残存リンクとして報告します。
