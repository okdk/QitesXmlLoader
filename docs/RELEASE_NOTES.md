# Qites xml loader 0.9

Windows向けの非公式iTunesライブラリXMLローダーです。XMLを読み、曲を選んで試聴・コピー・ハードリンク・音声変換できます。

0.9では、未検出時の停止／無視設定、ライブラリ全体の登録パスを使う同名ファイル参照、確認結果の件数ダイアログを追加しました。複数候補はそれぞれ存在を確認し、実在1件なら採用、2件以上なら未解決にします。

入力ローダーを切り替えられる構成にし、iTunes XMLを標準、単一フォルダを同梱サンプルとしました。画面なしで処理する`--pipe`モードは、UTF-8 JSON LinesでPythonなどから操作できます。[ローダー仕様](LOADERS.md)と[パイプ仕様・Python例](PIPE-PROTOCOL.md)を参照してください。日本語READMEを整理し、英語の仕様READMEも追加しました。

UNC参照の既定拒否と明示的なNAS許可、共有先の接続結果記憶、試行内の確認判断の記憶、コマンドの一括NG／承認指定を追加しました。新規リンク用の検査付き解除BATと、フォルダをドロップしてコマンド処理するBATサンプルも含みます。独立レビューの指摘に基づき、復旧失敗時の再試行、出力先の検証、大規模同期の照合、XMLの深度制限を修正しています。

0.9では、再生欄を1行にまとめ、シークと曲・プレイリストの時間表示を追加しました。狭い画面では経過時間を優先します。MusicBee・foobar2000・AIMP向けの相対パスM3U8/M3Uと、reTONE向けの連番付きMusicフォルダを出力できます。日本語のファイル名を保持し、必要な場合だけ英数字の互換名を選べます。reTONEは外部リストの読み込みに非対応です。詳しくは[書き出しと再生](EXPORT-PLAYBACK.md)を参照してください。

終了後に、処理済みのエラー履歴だけで空の「起動エラー」を表示するランチャーの判定も修正しました。未処理のエラーがある場合は、発生箇所を含むログを残します。

- 日本語／英語、言語ファイルでのフォント定義、システムフォントへの代替
- 通常／スマートの表示区別、親フォルダ階層、配下の全曲表示・選択追加
- Ctrl／Shift／ドラッグの複数行選択、プレイリストをまたぐ選択保持
- MP3、AAC/M4A、FLAC、ALAC、WAV、Opus、Ogg Vorbis、カスタム出力
- 音声出力デバイス保存、各種再生モード、共通進捗と停止・復旧
- XMLキャッシュとハッシュ差分照合

FFmpegは同梱しません。別途インストールしてアプリでパスを指定してください。未導入でもコピー・ハードリンク・Windows標準対応形式の試聴は利用できます。

Windows 10/11 x64・Windows PowerShell 5.1・.NET Framework 4.8が対象です。EXEは未署名です。スマートプレイリストはXML保存時点の内容を読み、条件の再評価やiTunes操作は行いません。Android実機・すべての形式・すべての出力デバイスの互換性を保証するものではありません。
