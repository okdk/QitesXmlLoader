# 0.9の検証と独立レビュー

検証日: 2026-10-24。Windows x64上で、生成した音声・XML・フォルダだけを使用しました。iTunesの起動や操作、実ライブラリの変更、ストア接続、購入は行っていません。

## 自動・画面検証

- 通常・スマート・親フォルダ、複数行選択、日英切り替えとフォント代替。言語キー250件の一致。
- シーク、再生時間、表示中リストの時間、狭い幅での表示、一時停止中のシーク、正常終了。
- FFmpegなしのコピー・ハードリンク・Windows標準再生。外部FFmpegのMP3、AAC、FLAC、ALAC、WAV、Opus、Vorbis、カスタム変換とffprobe確認。
- MusicBee・foobar2000・AIMP・reTONE向けの音声／相対パスリスト、移動後の参照、Unicodeと英数字互換名。
- 未検出時の停止・スキップ、ライブラリ全体からの同名候補、一意な実在候補の採用、複数実在候補の拒否、キャッシュ読込後の再確認。
- 単一フォルダローダーの直下だけの読込と名前順、既定iTunesローダー。
- JSON Linesの設定・読込・選択・書き出し・復旧・一時停止・再開・キャンセル・音声再生・シーク。一括NG／承認の起動引数。
- ロックされた生成物での部分復旧失敗と、ロック解除後の再試行。
- NAS接続は実接続せず、物理I/Oを模擬して、既定拒否、明示許可、共有先の成功／失敗の記憶、同じ失敗への再試行抑止を確認。
- 1000段の合成XMLを通常のエラーとして拒否し、その後の有効な読込が同じパイププロセスで成功。
- 解除BATの生成、確認表示、範囲外・元音声不在・コピー後のID不一致の拒否。途中失敗からの再試行は、通常のテキストファイルと模擬ID／削除関数で確認。
- フォルダドロップBATの処理本体を、合成フォルダからコピー出力して確認。

解除スクリプトによる実ハードリンクの削除は実行していません。テストの復旧処理で取り消したリンクは、そのテストが新規作成したものだけです。元音声とXMLのハッシュが変わらないことも確認しています。

## 独立したAIプロセスによるレビュー

開発履歴を引き継がない別のAIプロセスに、コード、ドキュメント、外部ライブラリのライセンスをレビューしてもらい、その後に別プロセスでセキュリティを確認しました。追加機能についてもコード・文書・セキュリティの再レビューを行いました。これは第三者機関の認証や安全保証ではありません。

主な指摘と対応:

- 部分復旧を完了扱いにせず、同じ操作を再試行できるよう修正。
- 拡張同期の相対出力先を、絶対化する前に拒否。
- 残存リンク照合をHashSetにし、全件の線形検索を繰り返す処理を変更。
- EOF／終了時の音声停止と、パイプ仕様・境界条件の記述を整合。
- XMLからの自動UNC参照を既定拒否にし、明示許可と共有先の接続記憶を追加。
- XMLの深さを、DOM変換前と再帰処理中の両方で制限。
- 解除の途中失敗後は、元音声のIDを確認して解除済みの出力を飛ばせるよう修正。
- FFmpegの場所と起動時の入力元確認も、NASの許可・失敗記憶を通すよう修正。
- 解除BATが正常完了時に生成されること、フォルダ移動／コピー時の制限、一括エラー方針の範囲を明記。

追跡した修正について、追加の重大なソース上の問題は指摘されていません。配布前には再ビルドと公開用ソースの再生成を行い、レビュー対象のソースと一致することを照合します。
